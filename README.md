## The icebreaker people actually want to play

Soc Ops gives every player a 5×5 board of conversation prompts. Find someone who matches a square, tap it, and connect five in a row. It takes seconds to learn, gets people moving, and turns small talk into stories.

**The loop is simple:**

1. **Start a game** and get a fresh board.
2. **Find your matches** by talking to the people around you.
3. **Mark the squares** as you discover shared experiences.
4. **Shout “Bingo!”** when you complete a line.

No accounts. No complicated rules. Just a lightweight game designed to get a room talking.

## ✨ What’s inside

- A responsive, touch-friendly 5×5 bingo board
- Fresh prompt boards generated by the Spring Boot API
- Persistent game state so a refresh does not lose your progress
- Clear lobby, active-game, and victory states
- A focused UI that works on phones, tablets, and desktop browsers
- A hands-on workshop for evolving the app with VS Code and GitHub Copilot

## 🚀 Run it locally

### Prerequisites

- [Java 21 JDK](https://adoptium.net/) or newer
- [Apache Maven 3.9+](https://maven.apache.org/) — or use the included Maven Wrapper

### Start the game

```bash
cd socops
./mvnw spring-boot:run
```

Then open [http://localhost:8080](http://localhost:8080) and start a round.

> On Windows, use `mvnw.cmd spring-boot:run` instead.

### Build and test

```bash
cd socops

# Create a production package
./mvnw clean package

# Run the test suite
./mvnw test
```

## 🧭 Explore the code

```text
socops/
├── src/main/java/com/socops/
│   ├── model/       # Bingo cells, phases, and winning streaks
│   ├── service/     # Board generation and game rules
│   └── web/         # Web and REST endpoints
├── src/main/resources/
│   ├── templates/   # Thymeleaf game screen
│   └── static/      # CSS and browser-side game engine
└── src/test/        # Service and behavior tests
```

The board endpoint is available at `GET /api/bingo/fresh-board`, while the browser client handles selection, persistence, and win detection.
